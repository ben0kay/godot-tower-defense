# Industrial Generator — FUTURE / NOT IMPLEMENTED

The reliable **standard starting/main generator** for most levels. Medium output and reasonable cost; a workhorse for ordinary connected terrain bases. Contributes power automatically to the grid on its landmass, extended to other islands only by deliberately linked relay pairs.

This is a **distinct generator building type** (not an upgrade of Solar), using common shared generator logic while retaining its own authored stats, scene/art and future independent purchased levels. Fuel consumption is not required initially; actual values remain undecided.
