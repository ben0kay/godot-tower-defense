# Solar Generator — FUTURE / NOT IMPLEMENTED

A cheap, sustainable **low-output** electricity building intended mainly for tiny, isolated asteroid islands. Its output enters the local connected-terrain grid automatically; it shares output with another island only after an explicit linked relay pair joins the grids.

Separate build-menu tower type and stable ID, using the same future generator code as Industrial and Fusion. Its own authored config, visuals and possible independent purchased levels belong in this folder; do not duplicate generation logic.

See [Power design](../README.md), [shared generator logic](../Shared/README.md). The older [SolarTower hybrid idea](../../SolarTower/README.md) remains a distinct unimplemented possibility; avoid duplicate catalog identities.
