## SALV1 — Scrap recovery and refined-metal economy (implementation plan only)

The [SALV1 implementation plan](SALV1_IMPLEMENTATION_PLAN.md) defines rare enemy scrap drops (1% base), Citadel salvage flights, direct physical delivery to a placeable Scrap Refinery, timed conversion to a new Refined Metal wallet resource, safe between-wave checkpoints and future research/metal tower extensions. **Not implemented; no gameplay behaviour changed.** Suggested values are provisional.
