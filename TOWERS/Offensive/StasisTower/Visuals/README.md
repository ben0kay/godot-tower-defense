## StasisTower recoil preset

StasisTowerRecoil.tres is assigned to the tower scene's Recoil.Style. Select that node or open the preset to tune Enabled, KickDistancePixels, KickSeconds, ReturnSeconds and MaximumOffsetPixels. Motion is local backward +Y on TurretPivot/RecoilRoot; the fixed base and aiming pivot are not displaced. The original composite icon remains unchanged. Per-instance controllers own runtime offsets; presets contain tuning only. Build/visual verification remains pending.
