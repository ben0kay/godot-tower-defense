# Shockwave Tower artwork

`shockwave_tower.svg` remains the original compact 48×48 purple/lilac omnidirectional emitter used as the Level 1 finished image and catalog/build icon. No rotating turret or directional muzzle exists.

The existing shared construction presenter swaps the one stationary `Sprite` texture between [initial construction stages](Construction/README.md) and [Level 2 upgraded artwork](Upgrades/README.md). Level 2 has a reinforced circular casing and larger glowing resonator, with two temporary progress composites. The actual travelling ring effect remains independent in the shared ShockwaveStyle; none of these art textures alters wavefront damage, radius or movement.
