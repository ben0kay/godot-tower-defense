# Blaster Cannon placeholder art

`blaster_cannon.svg` is the 64×64 **catalog icon / construction fallback composite**. The real finished Level 1 tower uses `blaster_cannon_base.svg` and `blaster_cannon_gun.svg` as independent fixed/rotating layers, which the placement ghost now mirrors automatically. Artwork never defines radius, falloff, collision or damage timing.

The paid Level 2 artwork and 35%/70% construction composites are under [Upgrades](Upgrades/README.md).
