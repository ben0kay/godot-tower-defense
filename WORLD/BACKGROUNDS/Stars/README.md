# Stars

`level001_space.svg` is a lightweight placeholder starfield/nebula backdrop rendered at 1600×1280 and scaled 4× in the level to cover the default 6400×5120 world. It is world-anchored and independent of TileMapLayers.

Replace it or add Sprite2D nebula/planet assets under the level's SpaceBackground groups. Resize scenery if changing map dimensions. Keep SpaceBackground behind terrain (z_index -20). Cosmetics never reserve cells or change terrain rules; optional parallax can be added later.
